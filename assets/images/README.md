# مجلد صور الفعاليات والأنشطة (Activities & Events Images)

هذا المجلد مخصص للصور الفوتوغرافية التوثيقية لفعاليات وأنشطة نادي كيمياء السعادة بجامعة فرحات عباس سطيف 1.

### كيفية إضافة صورة نشاط جديدة (إرشادات الفريق 5):
1. انسخ ملف الصورة إلى هذا المجلد (`assets/images/`) باسم واضح بالأحرف الإنجليزية الصغيرة والشرطة، مثل:
   - `activity-reception.jpg` (استقبال الطلبة الجدد)
   - `workshop-ai.jpg` (ورشة الذكاء الاصطناعي)
   - `box-of-happiness.jpg` (صندوق السعادة)
2. افتح الملف `data/gallery.js`.
3. اضبط خاصية `hasImage: true` وحدد المسار والوصف البديل المناسب `alt`.
4. افتح الموقع عبر Live Server وتأكد من ظهور الصورة بسلاسة وتناسق في المعرض.
5. لا تقم برفع صور ضخمة الحجم تزيد عن 500 كيلوبايت لضمان سرعة التحميل لجميع الطلبة.
