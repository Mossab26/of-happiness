# مجلد شعارات النادي (Club Logo Assets)

يحتوي هذا المجلد على الأصول والشعارات الرسمية المعتمدة لنادي كيمياء السعادة:

- `club-logo.png`: الشعار الرسمي المعتمد للنادي (The Chemistry of Happiness)، المستخدم في ترويسة الموقع وبطاقة الهوية.

### تنبيهات هامة للطلبة والمطورين:
1. لا تقم بتغيير اسم الملف `club-logo.png` دون تحديث مراجعته في ملفات المشروع (`index.html` و `data/gallery.js`).
2. يُفضل استخدام صيغ صور خفيفة وشفافة الخلفية (PNG أو SVG أو WebP) بدقة عالية مع الحفاظ على حجم ملف مضغوط لتسريع تحميل الموقع.
