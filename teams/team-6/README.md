# دليل الفريق 6: الانضمام والتواصل
## Team 6 — Join & Community Contact

### 1. مسؤولية الفريق (Responsibility)
الفريق 6 مسؤول عن قسم "انضم إلينا وتواصل معنا" (`#join`). يهدف القسم إلى شرح كيفية تواصل الطلبة مع نادي كيمياء السعادة والخطوات العامة للانضمام والمشاركة في المبادرات واللجان، وإدارة إعدادات التواصل في `data/contact.js` دون إظهار أي روابط وهمية.

### 2. الملفات المملوكة للفريق (Owned Files)
- `css/team-6-contact.css`
- `js/team-6-contact.js`
- `data/contact.js`
- `teams/team-6/README.md`

### 3. ملفات ممنوع تعديلها (Restricted Files)
- `index.html` (مملوك للفريق 7).
- ملفات باقي الفرق في `css/` و `js/` و `data/`.

### 4. فرع Git المخصص (Git Branch)
```bash
git checkout -b feature/team-6-contact
```

### 5. عقد التكامل والدوال (Integration Contract)
- يلتزم الفريق بتعريف الدالة:
  ```javascript
  function initContactSection() { ... }
  ```
- تقرأ الدالة كائن `window.CLUB_CONTACT` وتنشئ محتوى قسم الانضمام داخل `<section id="join">`.

### 6. ضوابط الدقة والمصداقية (Accuracy Rules)
- لا تنشئ استمارة تسجيل وهمية تطلب بيانات الطلبة وتدعي إرسالها دون وجود خادم خلفي أو رابط رسمي.
- طالما لم يتم اعتماد روابط شبكات التواصل الرسمية من إدارة النادي، يجب إبقاء الرسالة المحايدة المعتمدة:
  > "سيتم إضافة وسائل التواصل والاستمارات الرسمية هنا فور اعتمادها من إدارة النادي."
- عند توفر رابط استمارة Google Forms رسمية، يتم تفعيل الرابط الحقيقي داخل `data/contact.js`.

### 7. خطوات الاختبار والمعاينة (Testing Procedure)
1. تشغيل الموقع عبر Live Server في VS Code.
2. النقر على زر "تواصل معنا" والتأكد من التمرير السلس إلى قسم الانضمام.
3. مراجعة الخطوات الإرشادية وصندوق التواجد الميداني في جامعة فرحات عباس سطيف 1.

### 8. المخرجات المتوقعة (Expected Deliverable)
- واجهة واضحة وموثوقة تحترم خصوصية الطلبة وتمنحهم إرشادات عملية للانضمام.
- فتح Pull Request بعنوان: `feat(team-6): structure join guide and configurable contact channels`.
