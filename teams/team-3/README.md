# دليل الفريق 3: الأنشطة والمبادرات
## Team 3 — Activities & Category Filters

### 1. مسؤولية الفريق (Responsibility)
الفريق 3 مسؤول عن بناء وإدارة قسم "أنشطتنا" (`#activities`)، وتنسيق بطاقات الفعاليات، وتوفير نظام تصفية تفاعلي حسب التصنيفات العلمية والثقافية والتدريبية، والتعامل الذكي والآمن مع التواريخ غير المحددة مسبقاً، وإظهار رسالة لطيفة في حال عدم توفر أنشطة بتصنيف معين.

### 2. الملفات المملوكة للفريق (Owned Files)
- `css/team-3-activities.css`
- `js/team-3-activities.js`
- `data/activities.js`
- `teams/team-3/README.md`

### 3. ملفات ممنوع تعديلها (Restricted Files)
- `index.html` (مملوك للفريق 7).
- ملفات الفرق الأخرى في `css/` و `js/` و `data/`.

### 4. فرع Git المخصص (Git Branch)
```bash
git checkout -b feature/team-3-activities
```

### 5. عقد التكامل والدوال (Integration Contract)
- يلتزم الفريق بتعريف الدالة:
  ```javascript
  function initActivitiesSection() { ... }
  ```
- تقرأ الدالة مصفوفة `window.CLUB_ACTIVITIES` ومصفوفة `window.CLUB_ACTIVITY_CATEGORIES` وتقوم بإنشاء الأزرار والبطاقات داخل `<section id="activities">`.

### 6. ضوابط الدقة والمصداقية (Accuracy Rules)
- أسماء الأنشطة حقيقية ومعتمدة في النادي (مثل: استقبال الطلبة الجدد، كن طالب، من الفكرة إلى التخرج، صندوق السعادة، ورشة الإلقاء، أرواح تجرب، ورشة الذكاء الاصطناعي... إلخ).
- لا تقم باختراع تواريخ ماضية دقيقة أو نتائج وهمية لم يتم توثيقها رسمياً. استخدم تواريخ دورية أو عبارة "تاريخ يعلن لاحقاً".

### 7. خطوات الاختبار والمعاينة (Testing Procedure)
1. فتح `index.html` بواسطة Live Server في VS Code.
2. النقر على أزرار التصفية المختلفة (دعم طلابي، تطوير مهارات، أنشطة علمية...) والتأكد من تحديث البطاقات بسلاسة.
3. التأكد من ظهور حالة الفراغ المنظمة في حال لم تتطابق أي بطاقة مع التصنيف المختار.

### 8. المخرجات المتوقعة (Expected Deliverable)
- نظام بطاقات أنشطة متجاوب وتفاعلي 100% باستخدام Vanilla JS النقي دون أطر عمل خارجية.
- فتح Pull Request بعنوان: `feat(team-3): render activities cards and category filters`.
