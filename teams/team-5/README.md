# دليل الفريق 5: معرض الصور والأصول
## Team 5 — Media Gallery & Assets Management

### 1. مسؤولية الفريق (Responsibility)
الفريق 5 مسؤول عن قسم "معرض الصور" (`#gallery`) وإدارة الأصول في `assets/`. يتولى الفريق عرض الصور المتوفرة، والتعامل بحذر واحترافية مع الصور المفقودة أو التي لم يتم تصويرها بعد بحيث لا ينكسر التنسيق إطلاقاً، وتوفير بطاقات بديلة مصممة بعناية تحمل نص: "أضف صورة النشاط هنا" مع توجيه الطلبة حول كيفية وضع الصور الحقيقية لاحقاً.

### 2. الملفات المملوكة للفريق (Owned Files)
- `css/team-5-gallery.css`
- `js/team-5-gallery.js`
- `data/gallery.js`
- المجلدات `assets/images/` و `assets/logo/` (تنظيم الملفات داخلها)
- `teams/team-5/README.md`

### 3. ملفات ممنوع تعديلها (Restricted Files)
- `index.html` (مملوك للفريق 7).
- ملفات باقي الفرق في `css/` و `js/` و `data/`.

### 4. فرع Git المخصص (Git Branch)
```bash
git checkout -b feature/team-5-gallery
```

### 5. عقد التكامل والدوال (Integration Contract)
- يلتزم الفريق بتعريف الدالة:
  ```javascript
  function initGallerySection() { ... }
  ```
- تقرأ الدالة مصفوفة `window.CLUB_GALLERY` وتنشئ شبكة المعرض المتجاوبة داخل `<section id="gallery">`.
- تتضمن معالجة خطأ تحميل الصور `onerror` تلقائياً لمنع أي علامة صورة مكسورة في المتصفح.

### 6. ضوابط الدقة والمصداقية (Accuracy Rules)
- لا تضع صوراً عشوائية من الإنترنت (Stock Photos) أو صوراً لأندية أخرى على أنها فعاليات لنادي كيمياء السعادة.
- استخدم الشعار المعتمد المرفق في `assets/logo/club-logo.png`.
- للأنشطة التي لا تتوفر لها صور رسمية حالياً، استخدم حالة البطاقة البديلة الآمنة.

### 7. خطوات الاختبار والمعاينة (Testing Procedure)
1. تشغيل الموقع وفحص شبكة المعرض.
2. التحقق من ظهور شعار النادي بشكل نقي وواضح.
3. تجربة مسار غير صحيح لصورة والتأكد من تحولها التلقائي للبطاقة البديلة دون ظهور أي تشوه في التصميم.

### 8. المخرجات المتوقعة (Expected Deliverable)
- معرض صور احترافي، مرن، ومتوافق مع الهواتف والحواسيب.
- فتح Pull Request بعنوان: `feat(team-5): build responsive gallery with fallback placeholders`.
