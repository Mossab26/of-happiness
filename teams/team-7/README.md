# دليل الفريق 7: الصفحة الرئيسية والتكامل العام
## Team 7 — Home & Integration Architecture

### 1. مسؤولية الفريق (Responsibility)
الفريق 7 هو الفريق المسؤول عن هندسة التكامل والصفحة الرئيسية. يتولى هذا الفريق:
- إنشاء وصيانة وثيقة `index.html` الأساسية.
- ترتيب الأقسام الثابتة بالمعرفات الموحدة (`#home`, `#about`, `#activities`, `#team`, `#gallery`, `#join`).
- تطوير شريط التنقل العلوي المتجاوب، وقائمة الهواتف الذكية.
- تطوير قسم البداية الترحيبي (Hero Section) وشعار النادي.
- تطوير تذييل الصفحة (Footer) الذي يربط كافة أقسام الموقع وحقوق الملكية.
- كتابة منسق التكامل `js/team-7-home.js` الذي يستدعي دوال تهيئة الفرق الأخرى بأمان كامل.

### 2. الملفات المملوكة للفريق (Owned Files)
- `index.html`
- `css/team-7-home.css`
- `js/team-7-home.js`
- `teams/team-7/README.md`

### 3. ملفات ممنوع تعديلها (Restricted Files)
- ملفات CSS و JavaScript و Data الخاصة بالفرق من 1 إلى 6.
- الفريق 7 يمتلك التكامل العام وإدارة الهيكل، وليس التعديل الداخلي على منطق ميزات الفرق الأخرى.

### 4. فرع Git المخصص (Git Branch)
```bash
git checkout -b feature/team-7-home
```

### 5. عقد التكامل بين الفرق (Integration Architecture)
- يستدعي الفريق 7 دوال التهيئة التالية عند اكتمال تحميل الصفحة (DOMContentLoaded):
  1. `initAboutSection()` (الفريق 2)
  2. `initActivitiesSection()` (الفريق 3)
  3. `initTeamSection()` (الفريق 4)
  4. `initGallerySection()` (الفريق 5)
  5. `initContactSection()` (الفريق 6)
- يتم استخدام فحص `typeof fn === 'function'` قبل الاستدعاء مع `try...catch` لضمان عدم توقف الموقع حتى لو تأخر أحد الفروع.

### 6. خطوات الاختبار والمعاينة (Testing Procedure)
1. فتح `index.html` عبر Live Server.
2. تجربة النقر على جميع روابط القائمة والتأكد من التمرير السلس إلى الأقسام الصحيحة.
3. تجربة زر القائمة في الهواتف الذكية (فتح وإغلاق القائمة والتحقق من الاستجابة).
4. التحقق من كونسول المتصفح للتأكد من خلوه التام من الأخطاء.

### 7. المخرجات المتوقعة (Expected Deliverable)
- منصة ويب متكاملة، متناسقة، وسريعة الاستجابة تجمع أعمال الفرق السبعة في انسجام تام.
- فتح Pull Request بعنوان: `feat(team-7): assemble main page layout and responsive navigation`.
